# 六级通勤复习器 · CET6 Commute Reviewer

> 为通勤碎片时间设计的六级备考 App —— 一次 40 分钟的车程，就是一节完整的词汇 + 听力 + 写作课。

**纯离线 · 无网络权限 · 无账号 · 数据只存在本机**

## ✨ 功能特性

### 🏠 今日 — 40 分钟三阶段总控

- **0-10 分钟 词汇闪卡** → **10-30 分钟 听力精听** → **30-40 分钟 写作**，阶段切换震动提醒
- 进度自动持久化：地铁上被打断、App 被杀，重开后续学
- 完成后自动打卡；打卡日历、连续打卡天数一目了然

### 📚 学习 — 四个子栏目

| 栏目 | 内容 |
|------|------|
| 📖 词汇 | 2000 个六级高频词 SRS 闪卡（5 盒间隔重复），每轮新词数可调（10-60），生词本自动收录，支持 txt 批量导入自定义词表 |
| 🎧 听力 | 6 段精听素材（长对话/篇章/讲座，配音频与原文文稿），可导入真题 MP3 到任意套卷 |
| 📗 套卷 | 11 套完整试卷：2 套配音频模拟卷 + **2018-2026 年份冲刺卷**（写作题为历年真题），每套含写作/听力/阅读/翻译 + 答案解析 |
| ✍️ 作文 | 25 篇高分范文，6 大类别（现象阐释/观点论证/问题解决/名言引语/图表作文/热点话题），**标准考试卷面呈现**（卷头、字数统计、署名区），挖空/逐句/回忆三种背诵模式，TTS 朗读 |

### 👤 我的

- 每周目标（背词/听力/时长/打卡天数可自定义）与进度追踪
- 累计统计、月度打卡日历、生词本管理
- 设置：字号四档调节、每轮词数、主题（浅色/深色/跟随系统）、翻牌震动、清空学习数据

## 🛠 技术栈

- **Kotlin** + **Jetpack Compose** + **Material 3**
- 本地 **SQLite** 存储，无任何第三方网络库
- minSdk 26（Android 8.0）/ targetSdk 34

## 🔧 自行构建

**环境要求**：JDK 17、Android SDK（compileSdk 34）

1. 克隆仓库，用 Android Studio 打开（会自动下载 Gradle 与依赖）
2. 在 `local.properties` 中配置 SDK 路径：
   ```properties
   sdk.dir=D\:\\your\\path\\android-sdk
   ```
3. 构建 Debug 包：`gradle assembleDebug`
4. （可选）Release 签名：在 `local.properties` 追加密钥配置，并在 `keystore/` 放入你的 `.jks` 文件：
   ```properties
   RELEASE_STORE_PASSWORD=你的密钥库密码
   RELEASE_KEY_ALIAS=你的别名
   RELEASE_KEY_PASSWORD=你的密钥密码
   ```
   > ⚠️ 密钥文件与密码**严禁提交到仓库**（已在 .gitignore 中排除）。项目自带的签名密钥不随仓库分发。

## 📁 项目结构

```
app/src/main/
├── assets/
│   ├── words/          # 词库 20 个分片，共 2000 词
│   ├── papers/         # 11 套试卷 JSON
│   ├── listen/         # 听力音频(wav)+原文(txt)
│   └── essays.json     # 25 篇范文
└──/java/com/cet6/commute/
    ├── data/           # SQLite、导入器、仓库层
    ├── logic/          # 40 分钟三阶段计时器
    └── ui/             # Compose 界面(今日/学习/我的/设置)
```

## 📄 说明

- 词库按字母序分 20 个文件存放，启动时自动导入，便于增量扩充
- 年份卷听力部分为同难度仿真题，无内置音频，可在套卷内导入真题 MP3 搭配使用
- 本项目为个人备考工具，真题内容版权归原主办方所有，仅供学习交流
